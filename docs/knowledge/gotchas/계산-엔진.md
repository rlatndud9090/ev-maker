# 함정: 계산 엔진

### G-261115-engine-no-last-respects: 성묘 위력은 엔진에 맡기지 말고 코어 조건 lastRespectsFainted로 덮어쓴다
> 발견: 2026-11-15 · 유형: 외부제약 · area: 계산 엔진 · 출처: docs/raw/feature/damage-tabs-row-revamp/notes.md · 코드: `src/core/engine.ts:conditionMovePower`, `src/core/conditions.ts`

**규칙:** 성묘(lastrespects) 위력은 `conditions.lastRespectsFainted`(50×(1+n))로 코어가 덮어쓴다. 총대장용 `attacker.alliesFainted`와 섞지 않는다. 엔진 기술 데이터·mechanics에 위력 규칙이 있다고 가정하지 않는다.

**왜:** @smogon/calc champions mechanics에는 Last Respects 위력 규칙이 없어 항상 위력 50으로 계산됐고, 타부자고 방어 탭에서 대쓰여너 기본 기술이 성묘가 아니라 고스트다이브로 잡혔다.
