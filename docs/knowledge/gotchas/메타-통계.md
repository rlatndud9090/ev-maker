# 함정: 메타 통계

### G-261106-node-core-ts-hook: Node 명령에서 src/core를 import하는 스크립트는 확장자 보정 resolve 훅을 먼저 등록한다
> 발견: 2026-11-06 · 유형: 외부제약 · area: 메타 통계 · 출처: docs/raw/feature/meta-usage-stats/notes.md · 코드: `scripts/data/lib/ts-hooks.mjs`, `scripts/data/build-meta.mjs`

**규칙:** `scripts/` 아래 Node 진입점이 `src/core/*.ts`(확장자 없는 상대 import)를 쓰려면 `ts-hooks.mjs`를 먼저 import한 뒤 파이프라인을 동적 import한다. 검증은 Vitest가 아니라 실제 CLI 실행으로 한다.

**왜:** 생성 시 `validateSet`을 부르려다 Node 타입 제거만으로는 확장자 없는 import가 해석되지 않았다. Vitest는 자체 해석기로 통과해 누락이 테스트에서 드러나지 않는다.
