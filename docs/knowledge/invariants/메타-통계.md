# 불변식: 메타 통계

### INV-261106-meta-latest-gamedata-hash: 동결되지 않은 레귤레이션의 매치 방식별 최신 월 메타 스냅샷은 현재 게임 데이터 data.json 해시를 가리킨다
> area: 메타 통계 · 출처: docs/raw/feature/meta-usage-stats/adr.md#결정-2 · 코드: `src/data/meta-guard.ts:classifyGameDataRefs`, `scripts/data/lib/meta-pipeline.mjs` · 봉인: `src/data/meta-snapshot.test.ts`, `src/data/meta-loader.test.ts`

**위반 시:** 게임 데이터(보정표 등)를 바꾸고 최신 월 메타를 `--force`로 다시 만들지 않으면 이번 달 메타가 낡은 식별자·이름으로 재현성 검증에서 빠진다.

### INV-261106-meta-share-no-renormalize: 메타 분포 점유율은 위반 값을 뺀 뒤 재정규화하지 않고 원천 가중 출현 수를 분모로 둔다
> area: 메타 통계 · 출처: docs/raw/feature/meta-usage-stats/adr.md#결정-4 · 코드: `scripts/data/lib/meta-build.mjs:transformSource`, `scripts/data/lib/meta-build.mjs:shares` · 봉인: `src/data/meta-pipeline.test.ts`, `src/data/meta-snapshot.test.ts`

**위반 시:** 사용률·배분 점유율이 원천과 소수 자리까지 맞지 않아 원천 대조 수용 테스트가 깨지고, 빠진 몫(excludedShare)의 의미가 사라진다.

### INV-261106-no-ladder-custom-only: 래더 가정이 없는 종에는 통계 값·자동 기본 세트를 만들지 않고 커스텀 출처 가정만 붙인다
> area: 메타 통계 · 출처: docs/raw/feature/meta-usage-stats/adr.md#결정-3, docs/raw/feature/meta-usage-stats/prd.md · 코드: `src/meta/assumptions.ts:lookupOpponent`, `src/meta/assumptions.ts:resolveAssumption` · 봉인: `src/meta/assumptions.test.ts`, `src/data/meta-snapshot.test.ts`

**위반 시:** 사용률 0.5% 미만 종에 지어낸 기본 배분이 래더 가정처럼 섞여 카드 판정 근거가 오염된다(초기 프리셋은 화면이 커스텀 가정으로 채운다).
