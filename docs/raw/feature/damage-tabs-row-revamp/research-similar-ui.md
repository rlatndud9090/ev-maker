## 유사 UI/UX 서비스 리서치 보고서 (포켓몬 챔피언스 SP 구간 표)

조사일: 2026-11-13. 출처는 WebSearch와 WebFetch 결과다. 403으로 직접 열지 못한 페이지(Pokémon Zone, RotomPicks, ポケ徹)는 검색 요약에만 기댔고, 해당 항목에 따로 표시했다. 화면을 실제로 조작해 본 것은 아니다. 모든 내용은 각 사이트의 소개문·가이드 문구에 근거한다.

### 1. 우리와 가장 가까운 서비스

**1-1. VGC Multi Calc** ([사이트](https://vgcmulticalc.com/), [Team vs Many 가이드](https://vgcmulticalc.com/how-to-use/team-vs-many/), [SP Optimizer 가이드](https://vgcmulticalc.com/how-to-use/sp-optimizer/))
- (1) 제공하는 것
  - 모드: One vs One / Team vs Many(내 1마리 대 상대 목록) / Many vs Team(상대 목록 대 내 1마리) / Speed Calc / Probability Calc.
  - 상대 목록 출처: "My List", "Meta"(현 레귤레이션 최다 사용 포켓몬), 내 팀 중 하나. Meta 목록의 세트·배분을 어떻게 정하는지는 **미확인**이다. Meta 포켓몬을 고쳐도 새로고침하면 사라진다.
  - SP Optimizer: 생존(2/3/4HKO 견딤) 또는 KO 목표에 필요한 최소 SP를 구한다.
- (2) 우리와 겹치는 점
  - 공격 탭 ≈ Team vs Many, 방어 탭 ≈ Many vs Team, 스피드 탭 ≈ Speed Calc(메타 상위 필터 있음).
- (3) 참고할 UI 패턴
  - 결과 보기를 두 가지로 준다. **Cards**(상대 1마리당 카드 1장, 대미지와 KO 확률)와 **Dense**(OHKO/2HKO/3HKO/4HKO+ 그룹으로 묶고 대미지 순 정렬).
  - 레이아웃 전환: Stacked / Side by Side.
  - "Order by Damage" 정렬, "Best Move"(상대마다 가장 센 기술 자동 선택), Roll Level(Low/Med/High) 일괄 적용, 상대 전체에 방어/특방 랭크 일괄 적용.
  - 최적화 결과를 "60개 공격 중 53개를 52 SP로 버팀" 같은 커버리지 문장과 최악 상대로 보여 준다. 목표를 못 이루면 "Best effort: 28.9% chance to 2HKO"처럼 최선안을 낸다. 버튼은 Apply / Discard.
  - 모바일: 스프라이트 탭으로 고르고, Dense 보기에서는 길게 누르면 세트 정보를 보여 준다(가이드에 모바일 스크린샷 있음).
- (4) 우리만의 차별점
  - 상대 1종에 대해 **관측된 실사용 배분 분포(사용률 %)를 드롭다운으로 고르는** 기능은 확인되지 않았다.
  - SP를 바꾸면 판정이 바뀌는 "변동 가능" 표시가 없다. 이 서비스는 최소 SP를 한 번에 풀어 주는 방식이다.
  - 랭크업 변형 기술("+2 도각참") 후보 기능은 확인되지 않았다(일괄 랭크 수정자만 있음).

**1-2. 高千穂統計 ダメージ計算** ([사이트](https://www.damage.takachiho-toukei.com/), [攻撃視点](https://www.damage.takachiho-toukei.com/attacker))
- (1) 제공하는 것
  - 공격 쪽 또는 방어 쪽 노력치를 **0~32 전 구간(33단계)으로 한 화면에** 펼쳐 대미지·남은 HP·확정수가 바뀌는 경계를 보여 준다.
  - 그 밖의 도구: 耐久ライン(여러 상대 기준 등고선), EV最適化(지정한 견딤 확률을 맞추는 최소 H/B/D 배분), 素早さ比較(최대 5마리), 耐久指数.
- (2) 우리와 겹치는 점
  - 사실상 "SP 구간 표"라는 개념 자체가 같다. 내 SP를 바꿨을 때 판정이 바뀌는 지점을 보여 준다는 점에서 우리의 "변동 가능" 표시와 문제의식이 같다.
- (3) 참고할 UI 패턴
  - 33행 표 또는 그래프로 경계를 드러낸다. HP 0과 32를 겹쳐 그리고 원하는 HP 값도 올릴 수 있다.
  - 표의 색 구분과 "確定1発/乱数" 표기 형식은 **미확인**이다.
- (4) 우리만의 차별점
  - 이 서비스는 1대1 위주다. 메타 상위 상대를 한꺼번에 보여 주거나 사용률·배분 분포를 쓰는 기능은 사이트에 적혀 있지 않다(**미확인**).

**1-3. ポケナビ 対戦アシスト(試作)** ([사이트](https://pokenavi.jp/battle-assist/))
- (1) 제공하는 것
  - 챔피언스 채용률 데이터로 추정한 **"想定型"을 여러 개 만들어 채용률 높은 순으로 탭에 늘어놓는다.** 탭을 바꾸면 다시 계산한다.
  - 자신→상대 방향은 "確定2発/乱数2発", 상대→자신 방향은 기술별 받는 대미지와 남은 HP를 보여 준다. 6발 이상은 묶어서 표시한다.
  - 상대 검색은 히라가나로 할 수 있고, 사용률 순 목록에서 고를 수도 있다.
- (2) 우리와 겹치는 점
  - 상대 배분(型) 후보를 사용률 순으로 고르는 개념이 우리의 "배분(사용률 %) 드롭다운"과 같다. 방어 쪽에서 기술별로 받는 대미지를 보여 주는 것도 같다.
- (3) 참고할 UI 패턴
  - 型을 드롭다운이 아니라 **탭**으로 고른다.
  - "6발 이상"을 하나로 묶어 결과 표시를 단순하게 만든다.
  - 날씨·필드 기본값이 "特性まかせ"(특성으로 자동 판정)다.
  - 채용률 수치를 화면에 표시하는지는 **미확인**이다.
- (4) 우리만의 차별점
  - 이 서비스는 상대를 1마리씩 고르는 대면 방식이다. 페이지에 여러 상대를 일괄로 보여 준다는 설명이 없다. 스피드 판정과 SP 변동 표시도 없다.

### 3. 우리가 가져올 만한 아이디어 Top 5
1. **보기 전환: 카드 ↔ 확정수 그룹 Dense 보기** (VGC Multi Calc). 카드 목록 위에 "확정1타 / 난수1타 / 확정2타 / 그 이상" 그룹으로 묶는 압축 보기를 두면 400px 화면에서 훑어보기가 훨씬 빨라진다.
2. **커버리지 요약 한 줄과 최악 상대 표시** (VGC Multi Calc Optimizer). 탭 머리에 "상위 30마리 중 22마리 확정1타, 최악은 X"를 띄운다. "변동 가능" 카드 수까지 함께 세면 우리 고유 정보와 잘 맞는다.
3. **SP 구간 경계 시각화** (高千穂統計 33단계). "변동 가능" 배지를 누르면 "SP를 n 이상 주면 확정1타가 된다" 같은 경계값을 미니 바나 표로 펼친다.
4. **Best Move 자동 선택과 정렬 옵션** (VGC Multi Calc, Showdown One vs All). 판정 기술 기본값을 "상대마다 최대 대미지 기술"로 두고, 카드 정렬 기준(사용률 순 / 대미지 순)을 바꿀 수 있게 한다.
5. **래더 티어별 사용률 필터**(Porygon Labs)와 **지배적 선택지 자동 선택**(GameWith의 80% 넘는 특성). 사용률 데이터 출처를 필터로 고르게 하고, 압도적인 배분·도구는 자동으로 적용해 입력을 줄인다. 확정/가능 1타를 색으로 구분하는 방식(Champions Helper)은 우리 배지에도 바로 쓸 수 있다.

### 4. 이미 우리가 더 나은 점
- **상대 1종 안에서 실사용 SP 배분 분포(사용률 %)를 카드마다 고르는 기능.** 확인한 서비스 가운데 이것을 메타 일괄 목록과 함께 제공하는 곳은 없었다. ポケナビ는 型 탭이 있지만 1대1이고, VGC Multi Calc는 일괄 목록이 있지만 배분 분포는 **미확인**이다.
- **"변동 가능" 표시.** 내 SP를 바꿨을 때 판정이 뒤집히는 카드를 일괄 목록 안에서 바로 짚어 준다. 다른 서비스는 최소 SP를 풀어 주는 최적화(VGC Multi Calc, Pikalytics, 高千穂)나 1대1 구간 표(高千穂)에 그친다.
- **랭크업 변형 기술 후보("+2 도각참").** 다른 곳에서 확인한 것은 일괄 랭크 수정자나 개별 랭크 입력뿐이었다.
- **공격·방어·스피드 3탭을 같은 상대 목록과 같은 카드 문법으로 통합.** VGC Multi Calc는 모드 페이지가 따로 나뉘어 있다.
- **방어 탭 상대 기술 후보를 채용률 기준으로 자동 구성하고 기술 검색으로 추가.** 다른 서비스는 대부분 상대 기술 4개를 고정 세트로 쓴다.
- **사용자 배분 직접 추가를 일괄 목록 안에서 지원.** VGC Multi Calc의 Meta 목록은 고쳐도 새로고침하면 사라진다.

### 미확인 및 한계
- VGC Multi Calc Meta 목록의 세트·SP 출처, Showdown One vs All의 기준 세트, Pikalytics 기술 %의 의미, 高千穂·ポケナビ의 색과 배지 형식, 포챔랩의 일괄 계산 여부는 확인하지 못했다.
- Pokémon Zone, RotomPicks, ポケ徹은 403으로 직접 열지 못했고 검색 요약만 근거로 했다. ポケソル은 다회 공격·정수 대미지 계산까지만 확인했다. sv.pokedb.tokyo는 챔피언스용이 [champs.pokedb.tokyo](https://champs.pokedb.tokyo/pokemon/list?season=1&rule=1)(사용률 DB)이며, 자체 계산기가 있는지는 **미확인**이다.
