디자인 대안 비교 — 스피드 탭 개편 화면 배치

아래 대안을 비교하고, 베이스로 삼을 안 하나를 라디오로 선택한 뒤, 세부 수정 요구사항을 적어 주세요.

사용법
  1. 각 대안을 나란히 비교합니다.
  2. 가장 마음에 드는 안의 ◉ 라디오를 선택합니다(베이스 = 이 안을 출발점으로 발전).
  3. 대안별 칸과 아래 "전체 수정 요구사항"에 원하는 변경을 구체적으로 적습니다.
  4. "요약 생성"을 누르고 "복사"해서 에이전트에게 붙여넣습니다(이 파일은 정적이라 직접 전송되지 않습니다 — 붙여넣기로 전달).
공통 전제와 범례

세 시안 모두 같은 데이터다. 내 포켓몬은 종족값 98 가정, 현재 배분 S20 = · 실수치 138. 상위 30 중 일부 상대와 프리셋 1개, 기본 필터(랭크업·스카프·날씨/필드 켜짐, 순풍 꺼짐). 배지·필터·"내 순풍"·"다른 배분 추가"는 실제로 눌러 볼 수 있다.

이미지는 레포의 src/assets/를 상대경로로 불러오므로 이 파일은 레포 안 원위치(docs/raw/feature/speed-tab-revamp/)에서만 열 것. 옮기면 이미지가 깨진다. 키보드는 Tab 포커스·Esc 닫기만 흉내 냈다. 화살표(위아래 = 실수치 줄, 좌우 = 같은 줄 배지)·Home/End 이동은 ADR에서 정한다.

실수치 1 차이 ≈ 1.1px 비례, 24 넘는 간격은 "빈 구간" 빗금 띠로 압축. 줄 사이 최소 간격 보장.
상호작용
호버 250ms 지연·포커스·탭 → 배지 오른쪽 팝오버(공간 없으면 아래). 팝오버는 기준선 반대쪽으로 자란다(기준선 위 배지는 위로, 아래 배지는 아래로) — 기준선·동속 줄을 덮지 않게. 기준선이 화면 밖이면 "내 위치로" 버튼이 뜬다.
트레이드오프
폭을 배지에 다 써 같은 줄 줄바꿈이 적다. 대신 팝오버가 이웃 배지를 가린다 — 기준선 반대쪽으로 열어도 기준선 바로 옆 줄을 고르면 동속 줄 배지를 가릴 수 있다(차트 끝에서 공간이 모자랄 때). 기준선은 스크롤과 함께 사라져 버튼에 의존한다.
