디자인 대안 비교 — 조정 팝오버

아래 대안을 비교하고, 베이스로 삼을 안 하나를 라디오로 선택한 뒤, 세부 수정 요구사항을 적어 주세요.

사용법
  1. 각 대안을 나란히 비교합니다.
  2. 가장 마음에 드는 안의 ◉ 라디오를 선택합니다(베이스 = 이 안을 출발점으로 발전).
  3. 대안별 칸과 아래 "전체 수정 요구사항"에 원하는 변경을 구체적으로 적습니다.
  4. "요약 생성"을 누르고 "복사"해서 에이전트에게 붙여넣습니다(이 파일은 정적이라 직접 전송되지 않습니다 — 붙여넣기로 전달).

팝오버를 "조정" 버튼에 붙이고, 결과를 누르면 같은 자리에서 내용이 성격 선택으로 교체된다. 머리줄 ‹ 로 목록 복귀. 한 번에 한 단계만 보여 가장 좁고 단순하다.

팝오버 하나에 결과 목록을 두고, 항목을 누르면 그 바로 아래에 성격 선택지가 펼쳐진다. 다른 결과와 비교하며 고를 수 있지만 팝오버 높이가 늘어난다.

목록 대신 가로 칩으로 결과를 늘어놓고, 고르면 아래 줄에 성격 세그먼트가 나타난다. 두 단계가 한 패널에 함께 보이고 높이가 낮지만, 팝오버 폭이 넓다.

요약을 복사해 에이전트 대화창에 붙여넣으세요.
